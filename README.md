# ♟ CHESS GAME

Simple Chess game implementation in Java with UI made in Swing.

### FEATURES

- Full movement logic for all pieces (including castling and promotion)
- Handling core game rules and logic
- UI interactions
- Ability to reset the game
- Highligts possible moves for selected pieces

### FOCUS AREA

-  OOP principles
-  Event-driven programming
-  Game state management 
-  UI desing and interactions
